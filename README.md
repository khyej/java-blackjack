# java-blackjack

블랙잭 미션 저장소
---
## 사전학습
### [ 실험1 관찰 기록 ]
**1. 테스트케이스 3개**
- 사실 : 처음 테스트 케이스 3개로 실행했을 때 문제 2가지가 발생하였다.
- 문제 : 공백과 0이 입력될 경우의 처리가 되지 않았다.

**2. 테스트케이스 6개**
- 사실 : 테스트 케이스 3개를 추가했을 때, 문제 3가지가 발생하였다.
- 문제 : 음수의 경우, A가 입력되었을 경우, 10을 넘는 숫자가 입력되었을 경우의 처리가 되지 않았다.
 

### [ 실험2 관찰 기록 ]
**테스트가 어려웠던 코드**
<br>
- 현재 CardCalculator은 생성 시점에 데이터 검증을 하지 않는다. 
그래서 애초에 잘못된 데이터를 입력받았던건지 파악하기가 어렵다.

<br>

**바꾸고 싶은 부분과 이유**
<br>
- String으로 카드를 받지 않고 Card 객체를 따로 만들고 싶다. 
현재는 카드 합계를 할 때 각 카드의 점수를 계산하고 있는데, 
카드 자체가 점수를 알고 있으면 좀 더 역할이 분명할 것 같다.


---
**테스트 단위에 대한 내 의견**
<br>
- 하나의 클래스를 하나의 테스트 단위로 본다. 
그러면 각 객체가 자신의 역할을 제대로 하고 있는지 파악하기 쉽기 때문이다.
<br>

**반드시 테스트할 것**
<br>
- Card의 생성 검증 로직. 블랙잭의 핵심 규칙이므로 경계값(A, JQK, 음수 등)을 포함해 자세히 검증해야 한다.
<br>

**테스트하지 않을 것**
<br>
- 사용자에 대한 메시지 출력.
